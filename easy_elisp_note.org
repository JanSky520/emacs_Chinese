* 将 elisp 作为简单的计算器
-------
** 四种基本算术操作
-----
1. 四则运算的基本用法，及浮点数的转换
   #+begin_src emacs-lisp
     (+ 10 1)      ; 10 + 1 = 11
     (+ 1 2 3)     ; 1 + 2 + 3 = 6
     (- 5 3)       ; 5 - 3 = 2
     (* 2 4)       ; 2 * 4 = 8
     (/ 11 9)      ; 11 / 3 = 3 (会自动舍弃小数点)
     (/ 32 4 2)    ; 32 / 4 / 2 = 4
     (/ 11.0 3)    ; 11.0 / 3 = 3.6666666666666665 (运算数中带有小数点会自动进行浮点数运算)
   #+end_src
2. 四则运算的复杂用法
   #+begin_src emacs-lisp
     (* (+ 2 3) (- 5 3))          ; (2 + 3) * (5 - 3) = 10
     (* 3 (/ (+ 9 1) (+ 2 3)))    ; (9 + 1) / (2 + 3) * 3 = 6
   #+end_src
3. 练习 1：用 elisp 求解下列表达式
   + (1 + 39) * ( 53 - 45)
   + (1020 / 39) + (45 * 2)
   + 求和：39, 48, 72, 23, 91
   + 求平均值：39, 48, 72, 23, 91（结果取为浮点数）
** 其他算术操作
-----
1. 求余数和平方根
   #+begin_src emacs-lisp
     (% 10 3)    ; 10 % 3 = 1
     (sqrt 25)   ; 5.0 (求平方根默认用浮点数表示)
   #+end_src
2. elisp 支持三角函数的运算，诸如 sin，cos，tan，asin，acos 和 atan 等都支持在 elisp 中运算
   #+begin_src emacs-lisp
     (atan 1)    ; arctan1 = 0.7853981633974483
     (cos 0)     ; cos0 = 1.0
     (atan 1 0)  ; 表示 (atan y x)，其中 y 与 x 表示坐标轴 (x, y)
                 ; 本表达式对应的坐标为 (0, 1) 即表示点落在 y 轴上，表示 pi/2 即 arctan pi/2 = 1.5707963267948966
   #+end_src
3. 指数与对数的运算
   #+begin_src emacs-lisp
     (exp 2)     ; e^2 = 7.38905609893065
     (expt 2 3)  ; 2^3 = 8
     (log 27 3)  ; log3(27) = 3
   #+end_src

* 生成表
------
** Cons 单元和表
-----
1. Cons 单元是一个存放了两个地址的内存空间。Cons 单元可用函数 cons 生成
   #+begin_src emacs-lisp
     (cons 1 2)                      ; 执行后生产 (1 . 2)，cons 这个名字是术语构造 construction 的简称
     (cons 3 (cons 1 2))             ; (3 . (1 . 2)) 更方便地表示为 (3 1 . 2)，用链表的思维理解就是 [3] -> [1] -> [2]

     (cons (cons 0 1) (cons 2 3))    ; ((0 . 1) 2 . 3)，可以用二叉树来理解     [•]
                                     ; 头节点 [•] 生成左右子树                /   \
                                     ; 左子树 [0•1] 与右子树 [2•3]         [0•1] [2•3]
     
     (cons ?a (cons 3 "hello"))      ; (97 3 . "hello")，?a 表示 a 的 ASCII 码为 97，是个整数可直接用于数学计算
     (cons 'a' (cons 3 "hello"))     ; 如果执行这个表达式，会发现输出的结果是 (a cons 3 "hello")
                                     ; 原因是 elisp 中字符不能用单引号表示，而应该用双引号 “a” 表示一个字符串
                                     ; 该表达式实际上等价于 (cons 'a '(cons 3 "hello"))
   #+end_src
2. 列表实际上是由若干个 (cons car cdr) 构成的，并以特殊的 nil 值作为结尾
   #+begin_src emacs-lisp
     (cons 4 (cons 5 (cons 3 nil)))    ; (4 5 3)
     '(1 2 3)                          ; 等价于 (cons 1 (cons 2 (cons 3 nil))) <=> [1] -> [2] -> [3] -> nil
   #+end_src
3. 不使用 Cons 单元的数据结构称为原子 (atom)
   #+begin_src emacs-lisp
     (atom 42)      ; => t（整数是原子）
     (atom "hello") ; => t（字符串是原子）
     (atom '(1 2))  ; => nil（列表是 Cons 单元构成）
     (atom nil)     ; => t（nil 既是原子又是空列表）
   #+end_src

** 进一步认识 Cons 的概念
-----
1. quote 是一个非常重要的特殊形式，它用于防止表达式被求值
   #+begin_src emacs-lisp
     '(+ 2 3)       ; 代表列表 (+ 2 3) 本身
     '(cons 1 2)    ; (cons 1 2)
   #+end_src
2. 返回一个 Cons 单元的 car 部分和 cdr 部分的函数分别是 car 和 cdr 函数
   #+begin_src emacs-lisp
     (car '(1 2 3))       ; 1
     (cdr '(1 '(2 3)))    ; ('(2 3))
   #+end_src
