* 生成表
** Cons 单元和表
1. Cons 单元是一个存放了两个地址的内存空间。Cons 单元可用函数 cons 生成
   #+begin_src emacs-lisp
     (cons 1 2)                      ; 执行后生产 (1 . 2)，cons 这个名字是术语构造 construction 的简称
     (cons 3 (cons 1 2))             ; (3 . (1 . 2)) 更方便地表示为 (3 1 . 2)，用链表的思维理解就是 [3] -> [1] -> [2]

     (cons (cons 0 1) (cons 2 3))    ; ((0 . 1) 2 . 3)，可以用二叉树来理解     [•]
                                     ; 头节点 [•] 生成左右子树                /   \
                                     ; 左子树 [0•1] 与右子树 [2•3]         [0•1] [2•3]
     
     (cons ?a (cons 3 "hello"))      ; (97 3 . "hello")，?a 表示 a 的 ASCII 码为 97，是个整数可直接用于数学计算
     (cons 'a' (cons 3 "hello"))     ; 如果执行这个表达式，会发现输出的结果是 (a cons 3 "hello")
                                     ; 原因是 elisp 中字符不能用单引号表示，而应该用双引号 “a” 表示一个字符串
                                     ; 该表达式实际上等价于 (cons 'a '(cons 3 "hello"))
   #+end_src
2. 列表实际上是由若干个 (cons car cdr) 构成的，并以特殊的 nil 值作为结尾
   #+begin_src emacs-lisp
     (cons 4 (cons 5 (cons 3 nil)))    ; (4 5 3)
     '(1 2 3)                          ; 等价于 (cons 1 (cons 2 (cons 3 nil))) <=> [1] -> [2] -> [3] -> nil
   #+end_src
3. 不使用 Cons 单元的数据结构称为原子 (atom)
   #+begin_src emacs-lisp
     (atom 42)      ; => t（整数是原子）
     (atom "hello") ; => t（字符串是原子）
     (atom '(1 2))  ; => nil（列表是 Cons 单元构成）
     (atom nil)     ; => t（nil 既是原子又是空列表）
   #+end_src

* 局部变量
** let 表达式
1. 仅在作用域内生效，注意 let 后的括号
   #+begin_src emacs-lisp
     (let ((name "Alice")
           (age 30))
       (message "%s is %d years old" name age))    ; 仅在该作用域内生效

     (let ((x 10)
           (y 20))    ; 所有要绑定的变量整体用一个括号括起来
       (message "Sum: %d, Product: %d" (+ x y) (* x y)))

     (let ((x 2)
           (y x))    ; error 不能引用同级的变量
       (message "Inner x: %d, y: %d" x y))
   #+end_src
2. let 嵌套
   #+begin_src emacs-lisp
     (let ((x 1))
       (let ((x 2)
             (y x))  ; 不能引用同级的变量，这里的 x 来自外层 let，故 x = 1
         (message "Inner x: %d, y: %d" x y)))    ; "Inner x: 2, y: 1"

     (let ((x 10))             ; 外层 x
       (let ((x 20)            ; 内层 x 遮蔽了外层的 x
             (y x))            ; 这里的 x 是外层的 10
         (message "Inner x=%d, y=%d" x y))    ; Inner x=20, y=10
       (message "Outer x=%d" x))              ; "Outer x=10"
   #+end_src
** let* 表达式
1. 可以引用同级的定义
   #+begin_src emacs-lisp
     (let* ((x 10)

* 重复
** 递归函数
1. 在自己的定义中调用自己的函数叫做递归函数
   #+begin_src emacs-lisp
     (defun factorial (n)
       "计算 n 的阶乘"
       (if (<= n 1)
           1
         (* n (factorial (- n 1)))))
     (factorial 4)

     (defun double-elements (lst)                ; 递归能很好的处理表
       "递归地将表 LST 中的每个元素乘以 2"
       (if (null lst)                            ; 基本情况：空表
           nil
         (cons (* 2 (car lst))                   ; 当前元素翻倍
               (double-elements (cdr lst)))))
   #+end_src
2. 尾递归是一种特殊的递归形式，它可以被编译器优化为迭代，从而避免递归带来的堆栈溢出问题
   #+begin_src emacs-lisp
     (defun factorial-tail (n &optional acc)                              ; 第 1 次传参 fact (4)
       "使用尾递归计算 N 的阶乘，ACC 是累积器，默认为 1。"                ; 第 2 次传参 fact (3 4)
       (if (<= n 1)                                                       ; 第 3 次传参 fact (2 12)
           (or acc 1)                                                     ; 第 4 次传参 fact (1 24)
         (factorial-tail (- n 1) (* n (or acc 1)))))                      ; 返回结果 24
   #+end_src
